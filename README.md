# ✅ To-Do List — Organize Your Day

A simple and clean To-Do List web application built using **HTML, CSS, and JavaScript** to help manage daily tasks and stay organized.

> Add tasks, keep track of what needs to be done, and mark your progress—all in one place.

## ✨ Features

- ➕ **Add Tasks** – Create tasks quickly using the input field or Enter key.
- ✏️ **Edit Tasks** – Update task descriptions whenever needed.
- 🗑️ **Delete Tasks** – Remove tasks you no longer need.
- ☑️ **Mark as Completed** – Track finished tasks.
- 🔎 **Filter Tasks** – View all, active, or completed tasks.
- 📊 **Task Counter** – Keep track of remaining and completed tasks.
- 💾 **Persistent Storage** – Tasks are saved in Local Storage and remain available after refreshing the page.
- 📱 **Responsive Design** – Simple interface designed to work on different screen sizes.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/tvshetty-x/todo-list.git
   ```

2. Open the project folder.

3. Navigate to the `frontend` folder.

4. Open `index.html` in your browser.

That's it! You can start adding and managing your tasks.

## 💡 How It Works

The application uses JavaScript to manage tasks and update the webpage dynamically.

- Tasks are stored as objects in an array.
- The DOM is updated whenever a task is added, edited, deleted, or completed.
- Local Storage saves the task data in the browser.
- Filters display tasks based on their completion status.
